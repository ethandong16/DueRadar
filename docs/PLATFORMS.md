# 平台接入与支持范围

本文件描述 DueRadar 的公开支持边界、验证方法和未知值处理，不记录任何真实账号、课程、个人任务或一次性运行结果。

## 支持范围

- 平台登录应通过官方扫码或受支持的辅助登录流程完成。
- 任务同步使用独立 HTTP 会话；会话凭据保存在本地加密数据目录。
- 作业、考试、视频和课堂活动等任务类型按平台提供的字段映射。
- 课堂答题读取只对学生身份生效；教师和助教课堂不调用学生端答题接口。
- 平台未提供的时间、状态或进度保持未知，不用推测值触发提醒。
- 新增平台字段或任务类型应先增加模拟响应和回归测试，再宣称支持。

## 雨课堂随堂选择题助手（可选，待真实课堂验收）

- 原有课上答题提醒保持只读。随机兜底和 AI 分析是另外两个独立、默认关闭的开关，不使用提醒列表中按时间合成的标识提交答案。
- 动作通道只接受明确的学生角色 `5`。通过旧版学生只读入口 `/v/lesson/lesson_info_v2` 获取真实题目标识、选项和本人作答状态，再通过 `/wsapp/` 的题目时间线与倒计时消息调度；只处理 `MultipleChoice` 和 `MultipleChoiceMA`。
- 随机兜底在最后 10 秒重新读取本人作答状态，并要求新的倒计时响应回传本次查询的 `msgid`。续时、关闭或课次结束使旧预检失效；未知／无限倒计时、缺失／畸形作答状态、已答或不受支持的题型均跳过。多选兜底也只选一个字母，不保证正确。
- 唯一的答题写入口为 `/v/lesson/answer_lesson_problem`；先持久化动作占位，再进行一次提交，不因超时或未知结果更换答案重试。平台返回“已答”时不走重答接口。手动操作仍可能与最后一次请求竞争，已经被平台接收的请求无法撤回。
- 不自动签到，不调用 V3 的 `/api/v3/lesson/checkin`，也不因旧版入口失败切换到需要签到的路径。仅有 V3 能力的课堂可能不可用；作业、试卷、考试、投票、匿名投票和签到不在动作范围内。
- AI 只为随堂选择题生成 Bark 参考答案，不把模型结果交给提交接口。用户独立提供 Anthropic Key，题目资料会发送给 Anthropic；公开课件图片仅从固定 HTTPS 来源读取，不附带平台凭据，不跟随重定向。
- 协议映射来自公开客户端静态源码和本地模拟 HTTP／WebSocket 测试，不等于真实课堂已接受提交。旧版入口覆盖、成功状态码、图片来源以及实际 Bark 到达延迟均待独立验收；未进行真实答题、签到或付费模型调用。

## 知到课堂投票

当前完成的是官方学生前端的只读静态研究，尚未实现或验收实时投票监测。具体接口、来源证据和接入方案见 [知到课堂投票研究](ZHIDAO-VOTES.md)。

- 新版校内课存在独立读取链路：`/student-course/lesson/live/list` 发现课次，`/student-app/interaction/waterfall/list-all` 获取互动快照，识别 `IN_CLASS::TOOL-VOTE::PUBLISH`，将 `bizId` 作为 `voteId` 查询 `/student-app/api/vote/getVoteDetail`。
- 已有会话能否在不调用入课接口的情况下读取、token 与课程上下文的兼容性、投票仍开放及本人已参与状态，均需独立验证。缺字段或时间语义未知时不猜测；新版证据不代表旧版翻转课或共享课也受支持。
- 建议先验证独立的短周期 HTTP 只读监测，首次完整快照建立静默基线，按课次与投票标识持久化去重；15 分钟任务同步不能称为实时监测。官方 IM 初始化混有入课等副作用，不直接照搬。
- 不触发入课、投票、答题提交或签到，不读取／输出真实凭据和个人快照，也不将同学的参与明细写入任务、日志或通知。

## 验证方法

1. 在隔离测试账号或模拟响应中验证登录状态、分页、时间语义和完成状态。
2. 分别核对首次同步、重复同步、状态变化、会话复用和失败恢复。
3. 记录平台数量、任务数量、耗时和资源数据时，使用合成或匿名数据；不要提交账号、课程名称、设备标识或原始响应。
4. 真实平台验证必须由部署者在本地完成，公开报告只保留方法、能力边界和可复现的测试结果。

共享课、密码登录、验证码和长期会话续期等能力，只有在独立验证后才能标记为已支持。
