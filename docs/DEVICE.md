# 设备兼容性说明

DueRadar 面向小型 Linux 设备和自托管服务器。公开文档只描述能力要求，不发布任何真实设备型号、内核版本、资源快照、常驻服务或网络信息。

最低要求由部署者根据目标架构确认：

- 支持 Go 构建产物所需的 Linux 用户空间和目标架构。
- 有可写且支持文件锁的持久化数据目录。
- 能安全保存加密凭据和环境配置。
- 可选 Docker、systemd、VPN 或反向代理能力应分别验证，不视为必需依赖。

推荐使用 `scripts/device-audit.sh` 和 `scripts/measure.sh` 在本地采集配置与资源数据。原始输出不要提交；公开报告只保留匿名化的测试条件、结论和限制。
