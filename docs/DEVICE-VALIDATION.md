# 设备部署验证方法

本文件提供与设备无关的部署和观察清单，不记录具体型号、内核、网络地址、进程号、部署路径、备份路径或个人运行数据。

## 部署前

- 确认目标架构、操作系统、可用内存、存储空间和容器支持。
- 为数据目录和环境文件设置最小权限；不要把凭据或原始状态加入 Git。
- 确认服务监听范围、反向代理 HTTPS 和管理认证配置。

## 运行中

- 检查健康接口、服务状态、登录保护、设置持久化和数据目录锁。
- 分别观察空闲、同步、会话验证和通知发送阶段的 CPU、RSS、峰值、延迟与错误。
- 观察应记录采样条件、时长、样本数和限制；个人设备信息保留在本地忽略目录。

## 回滚

停止服务后备份完整数据目录和当前二进制，替换版本并检查健康接口。若回滚，必须同时恢复兼容版本的数据备份；验证完成后确认服务状态、设置和任务数据均符合预期。
