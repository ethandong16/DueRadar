# 平台接入与支持范围

本文件描述 DueRadar 的公开支持边界、验证方法和未知值处理，不记录任何真实账号、课程、个人任务或一次性运行结果。

## 支持范围

- 平台登录应通过官方扫码或受支持的辅助登录流程完成。
- 任务同步使用独立 HTTP 会话；会话凭据保存在本地加密数据目录。
- 作业、考试、视频和课堂活动等任务类型按平台提供的字段映射。
- 课堂答题读取只对学生身份生效；教师和助教课堂不调用学生端答题接口。
- 平台未提供的时间、状态或进度保持未知，不用推测值触发提醒。
- 新增平台字段或任务类型应先增加模拟响应和回归测试，再宣称支持。

## 雨课堂随堂选择题助手（可选，待真实课堂验收）

- 原有课上答题提醒保持只读。随机兜底和 AI 分析是另外两个独立、默认关闭的开关，不使用提醒列表中按时间合成的标识提交答案。
- 动作通道只接受明确的学生角色 `5`。通过旧版学生只读入口 `/v/lesson/lesson_info_v2` 获取真实题目标识、选项和本人作答状态，再通过 `/wsapp/` 的题目时间线与倒计时消息调度；只处理 `MultipleChoice` 和 `MultipleChoiceMA`。
- 随机兜底在最后 10 秒重新读取本人作答状态，并要求新的倒计时响应回传本次查询的 `msgid`。续时、关闭或课次结束使旧预检失效；未知／无限倒计时、缺失／畸形作答状态、已答或不受支持的题型均跳过。多选兜底也只选一个字母，不保证正确。
- 唯一的答题写入口为 `/v/lesson/answer_lesson_problem`；先持久化动作占位，再进行一次提交，不因超时或未知结果更换答案重试。平台返回“已答”时不走重答接口。手动操作仍可能与最后一次请求竞争，已经被平台接收的请求无法撤回。
- 不自动签到，不调用 V3 的 `/api/v3/lesson/checkin`，也不因旧版入口失败切换到需要签到的路径。仅有 V3 能力的课堂可能不可用；作业、试卷、考试、投票、匿名投票和签到不在动作范围内。
- AI 只为随堂选择题生成 Bark 参考答案，不把模型结果交给提交接口。用户独立提供 Anthropic Key，题目资料会发送给 Anthropic；公开课件图片仅从固定 HTTPS 来源读取，不附带平台凭据，不跟随重定向。
- 协议映射来自公开客户端静态源码和本地模拟 HTTP／WebSocket 测试，不等于真实课堂已接受提交。旧版入口覆盖、成功状态码、图片来源以及实际 Bark 到达延迟均待独立验收；未进行真实答题、签到或付费模型调用。

## 知到课堂投票

已提供默认开启（可主动关闭）的实验性只读监测；2026-11-10 已在真实课堂验证会话、课次、信令与详情读取，新投票的实时 Bark 到达仍待观察。具体接口、来源证据、实现边界和未知项见 [知到课堂投票研究](ZHIDAO-VOTES.md)。

- 新版校内课存在独立读取链路：`/student-course/lesson/live/list` 发现课次，`/student-app/interaction/api/lesson/check/finish` 过滤已结束课次，`/student-app/interaction/waterfall/list-all` 获取互动快照，识别 `IN_CLASS::TOOL-VOTE::PUBLISH`，将 `bizId` 作为 `voteId` 查询 `/student-app/api/vote/getVoteDetail`。
- 课堂请求只使用 `ai-poly` Cookie 的原值 `Authorization`；缺少该 Cookie 时明确报错，不回退 `jt-cas`，也不改变现有任务同步的 token 优先级。
- 首次完整快照建立静默基线，最近 2 分钟内发布的投票仍会提醒；之后按 `lessonId + bizId` 持久化去重。快照失败或畸形时不当成空列表，也不建立基线。`isFinish` 只表示本账号是否已投票；已投票或已结束的投票静默记录，结束时间未知时仍提醒并注明“状态暂未确认”。
- 已有会话能否在不调用入课接口的情况下读取、`live/list` 的实际查询范围、token 与课程上下文的兼容性、投票删除／延时语义，均需独立验证。新版证据不代表旧版翻转课或共享课也受支持。
- 不触发入课、投票、答题提交或签到，不读取／输出真实凭据和个人快照，也不将同学的参与明细写入任务、日志或通知；通知只提示打开知到，不包含自动投票能力。

## 验证方法

1. 在隔离测试账号或模拟响应中验证登录状态、分页、时间语义和完成状态。
2. 分别核对首次同步、重复同步、状态变化、会话复用和失败恢复。
3. 记录平台数量、任务数量、耗时和资源数据时，使用合成或匿名数据；不要提交账号、课程名称、设备标识或原始响应。
4. 真实平台验证必须由部署者在本地完成，公开报告只保留方法、能力边界和可复现的测试结果。

## 知到登录自动续期（可选，实验性）

- `jt-cas` 是 24 小时 JWT，`ai-poly` 等 token 与 SSO 会话同时失效；官方前端没有刷新接口，静默换票不可行。默认仍只用 APP 扫码绑定，不保存平台密码。
- 开启后，手机号和密码只写入该账号的加密 vault；状态接口只返回掩码手机号、是否已配置和会话到期时间，从不返回密码。
- 到期前约 1 小时触发官方 `validateAccountAndPassword` 与 `passport/login` 流程。平台要求短信二次验证时，从部署的只读短信模块按消息 id 和导入时间读取新验证码，最多等待 90 秒。
- 图形验证码、滑块、额外身份绑定、密码错误或账号受限时不尝试绕过，记录固定诊断并等待用户扫码。
- 滑块验证有手动通道：`/slider.html` 页面用 vault 里已保存的手机号和密码，只把网易易盾滑块交给用户在手机上滑一次。滑块通过后由服务端用 AES-CBC 加密的账号密码加 `validate` 调用登录中心 `zhsuser/login/account`，再走 `passport/login?service=` 换票，全程密码不进入浏览器。该页面的 CSP 单独放开易盾相关域名（`*.126.net`、`*.127.net`、`*.163.com`、`*.163yun.com`、`*.netease.com`）和 `'unsafe-eval'`，仪表盘自身的 CSP 保持同源限制。
- 新会话必须与已绑定的 `userNid` 一致，并且只在登录代际和旧会话都未变化时写入；手动扫码或另一轮登录优先，过期的自动登录结果会被丢弃。
- 短信模块需设置 `DUERADAR_SMS_API_URL` 与 `DUERADAR_SMS_API_TOKEN`；可用 `DUERADAR_SMS_KEYWORDS`、`DUERADAR_SMS_SENDERS` 收窄匹配。服务只读最近短信，不记录正文或验证码。
- 真实账号何时触发二次验证、验证码短信格式、每日发送限额和长期稳定性仍需部署者实测；完成验收前不得标记为稳定支持。

共享课、密码登录、验证码和长期会话续期等能力，只有在独立验证后才能标记为已支持。
