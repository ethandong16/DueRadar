# 普通雨课堂电脑辅助登录

这个流程在电脑上打开雨课堂官方登录页，供你使用账号密码和平台验证码。DueRadar 管理页面与辅助程序不接收账号密码；辅助程序在官方登录成功后把当前浏览器的雨课堂会话交给设备，设备再次验证后加密保存。

普通雨课堂微信扫码仍可直接使用。电脑辅助登录的自动化验证使用模拟平台；真实密码／验证码登录和跨设备接续仍需分别验收。

## 首次安装

只在辅助电脑安装 Python 3.10 或更新版本和本仓库源代码。在项目目录执行：

```sh
python -m pip install -r scripts/requirements-assist.txt
python -m playwright install chromium
```

这些依赖仅属于电脑辅助程序。小型 Linux 设备 和服务端程序继续使用独立 HTTP 同步，不安装或常驻浏览器。也可在已有 Python 虚拟环境中安装依赖。

## 开始登录

1. 在 DueRadar 的「平台账号」中选择普通雨课堂的「账号密码登录（电脑辅助）」。页面显示实例地址、流程编号和一次性配对码，配对从创建起 5 分钟有效。
2. 在电脑项目目录运行下方命令。依次粘贴实例地址、流程编号和配对码；配对码输入时不回显，也不放进命令行参数。
3. 辅助程序打开一个独立浏览器窗口。在雨课堂官方页面选择账号密码方式并完成验证码。程序不接入已有浏览器个人资料，也不自动填写、重试密码或处理验证码。
4. 页面显示「设备正在独立验证登录会话」后等待结果。确认登录后辅助浏览器自动关闭，设备开始另一轮任务同步；任务读取是否成功在平台卡片单独展示。

```sh
python scripts/rain_assist.py
```

实例地址和流程编号也可作为非敏感参数传入：

```sh
python scripts/rain_assist.py --instance https://你的实例域名 --flow 页面上的流程编号
```

如已安装 Chrome 或 Edge，可追加 `--browser-channel chrome` 或 `--browser-channel msedge`，仍使用辅助程序创建的独立上下文。

配对码只使用一次，上传会话也只允许一次。程序不会打印或保存密码、验证码和 Cookie。浏览器关闭、程序退出或管理页面取消后，重新开始一次配对即可；如果创建的新流程替代旧流程，旧流程的结果不会覆盖新会话。

## 实例地址

辅助程序固定连接你输入的实例地址，拒绝重定向和系统代理。公网域名使用有效 HTTPS；HTTP 只接受本机回环地址或 Tailscale 的字面 IP（IPv4 `100.64.0.0/10`、IPv6 `fd7a:115c:a1e0::/48`）。Tailscale 地址应属于你正在访问的实例并已连接对应网络。普通局域网地址或域名须配置 HTTPS，或使用 SSH 转发到回环地址。

程序不接受地址中的用户名、密码、查询参数、片段或子路径。网页登录与辅助程序使用同一个实例根地址；反向代理保持原始 Host。

## 状态与恢复

| 状态 | 含义与操作 |
| --- | --- |
| 等待辅助程序 | 启动命令并输入页面信息。 |
| 等待官方登录 | 在新窗口中完成账号密码与验证码；配对码已消费，页面清除它。 |
| 正在验证 | 设备验证身份并保存会话，请等待结果。 |
| 已登录 | 会话已保存；继续查看单独的任务同步结果。 |
| 已取消／已过期 | 原流程停止，关闭弹窗后重新发起。 |
| 失败 | 原始平台响应不会显示在页面。根据页面的验证或保存错误检查网络、数据目录，再新建流程。 |

成功配对不代表登录成功，浏览器跳转也不代表身份验证成功。后台只接受允许范围内、大小受限的 Cookie 元数据；空会话、外部域、重复字段和异常内容会被拒绝。登录过程中设备仍保留原有加密凭据，只有验证通过的会话才会替换它。

关闭管理弹窗、退出管理账号或开始新的扫码／辅助流程，会撤销相关配对。成功登录后，可以关闭辅助程序和电脑；设备独立运行的长时间效果仍按 [验收记录](ACCEPTANCE.md) 检查。
